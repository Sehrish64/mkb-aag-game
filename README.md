# MKB AAG — Retro Platformer

A retro 3-level platformer browser game, built from Sehrish's design doc. One
self-contained HTML file — open it in any modern browser (desktop or mobile)
and play, no build step, no server.

## The game

- **3 themed levels:** Beach → Snow → Castle
- Run, jump, collect; water and fire deal damage with instant respawn
- Level completion flow, victory screen, game over / retry
- Menu → play → pause flows; keyboard controls, mobile-friendly layout
- Zero external dependencies at runtime (single file)

## Play

Open `mkb-aag-game.html` in a browser, or play the hosted copy once the
GitHub Pages link below is enabled.

## Files

- `mkb-aag-game.html` — the complete game (single file, ~872 KB)
- `hero.png`, `collectible.png` — source character sprites
- `collectible_t.png`, `hero_t.png`, `qa_*.png` — sprite/QA variants
- `build/` — build-stage split sources
